## Вход в уровень: Junior → Middle

Источник правды — раздел «Критерии перехода на Middle» в
`PYTHON_BACKEND_ROADMAP.md`. Коротко:

- Идиоматичный Python без копирования из туториалов (comprehensions,
  контекстные менеджеры, `dataclasses`)
- Понимание `is`/`==`, mutable/immutable, ловушки mutable default
- Уверенный SQL с JOIN-ами + понимание, что генерирует ORM
- 2–3 законченных pet-проекта, один — REST API с БД
- Все блоки 2.1–2.10 пройдены (финальные оценки в `assessments/` —
  ≥80%)

## Выход из уровня: Middle → Senior

Источник правды — раздел «Критерии перехода на Senior» и «Сводный
чек-лист Middle → Senior» в `PYTHON_BACKEND_ROADMAP.md`. Коротко:

- Может в одиночку поднять сервис с нуля: API, БД, миграции, тесты,
  Docker, CI
- Понимает GIL, разницу async/threads/processes, осознанно выбирает
  модель под задачу
- Уверенно типизирует сложные кейсы, настраивает strict mypy/pyright
- Чинит N+1, читает `EXPLAIN ANALYZE`, оптимизирует запросы
- 3–4 законченных pet-проекта Middle (минимум один с Docker Compose
  и CI), сервис задеплоен и доступен публично
