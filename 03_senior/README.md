## Вход в уровень: Middle → Senior

Источник правды — раздел «Критерии перехода на Senior» в
`PYTHON_BACKEND_ROADMAP.md`. Коротко:

- Может в одиночку поднять сервис с нуля: API, БД, миграции, тесты,
  Docker, CI
- Понимает GIL, разницу async/threads/processes, осознанно выбирает
  модель под задачу
- Уверенно типизирует сложные кейсы, настраивает strict mypy/pyright
- Чинит N+1, читает `EXPLAIN ANALYZE`, оптимизирует запросы
- Понимает trade-offs архитектурных решений и умеет их аргументированно
  обсуждать
- Может провести code review и обосновать каждое замечание

## Senior — уровень без формального выхода

В отличие от Junior/Middle, у Senior нет фиксированного чек-листа
«готов к следующему уровню» — рост продолжается непрерывно
(«Сводный чек-лист Senior» в `PYTHON_BACKEND_ROADMAP.md` расписан как
постоянно развивающийся, не завершаемый). Ориентиры роста —
распределённые системы, observability, security, менторство — там же.
