# SQLAlchemy Core — основные объекты и мнемоники

## Engine — «двигатель машины»
Хранит настройки подключения к БД (диалект + пул соединений). Создаётся один раз на всё приложение:
```python
engine = create_engine("postgresql://...")
```

## Connection — «телефонная трубка»
Реальное открытое соединение с БД, через которое идут запросы. Берётся из Engine на время работы:
```python
conn = engine.connect()
```

## MetaData — «каталог/реестр»
Контейнер, который хранит информацию обо всех таблицах вашей схемы. Как папка, в которую складываются описания всех столов в доме.

## Table — «чертёж стола»
Описание одной таблицы БД (имя, столбцы, ключи) внутри MetaData:
```python
users = Table("users", metadata, Column("id", Integer, primary_key=True))
```

## Column — «ячейка чертежа»
Описание одного столбца таблицы: имя, тип данных, ограничения (PK, nullable, default).

## types (Integer, String, DateTime...) — «этикетки на ячейках»
Определяют, какой тип данных хранится в столбце и как он мапится Python ↔ SQL.

## select() / insert() / update() / delete() — «глаголы действия»
Конструкторы SQL-выражений в виде Python-объектов, а не строк текста. Мнемоника: SQL-глаголы = функции с теми же именами.

## Expression (ColumnElement) — «кирпичики фразы»
Объекты вроде `users.c.age > 18`, которые комбинируются в условия WHERE/JOIN.

## text() — «сырой текст»
Обёртка, когда хочется написать чистый SQL-текст, но всё равно передать через SQLAlchemy:
```python
text("SELECT * FROM users")
```

## Result / CursorResult — «поднос с блюдами»
Объект, который возвращает `connection.execute(...)` — по нему потом бегают через `.fetchall()`, `.fetchone()`.

## Transaction — «контракт с подписью в конце»
Группа операций, которые либо все применяются (`commit()`), либо все откатываются (`rollback()`).

---

### Общая мнемоника цепочки

**Engine → Connection → (MetaData → Table → Column) → Expression → Result**

то есть: «завод → труба → чертежи → детали → продукт»
